# 小猫便签 · 简体中文商店文案

Chrome 网上应用店和 Microsoft Edge 加载项可共用以下名称、简介和详细介绍。商店语言选简体中文，分类建议选效率工具（Productivity）。

## 名称

小猫便签

## 简介

选中网页文字即可存入当前便签。在侧栏写笔记、预览 Markdown，按标题或正文搜索，一键导出全部便签。

## 详细介绍

读到值得留存的一段话，在网页上选中它，点击「存入当前便签」。继续读另一篇文章时，也可以把新摘录追加到同一张便签。第一次摘录会自动创建便签，之后的选文按保存顺序排在一起。每张便签记录最近一次摘录的网址，方便导出后回访。

从浏览器工具栏打开小猫便签，在侧栏直接写下自己的想法。标题可以留空，输入会自动保存在本机。编辑时可以直接写 Markdown，切换到「预览」即可查看标题、引用和列表的排版。换一个主题时，点击「新建」即可开始草稿，写下文字或存入第一段摘录时才会出现在列表里。也可以从列表切回已有便签，继续追加摘录。

打开「全部便签」，输入标题中的几个字，或搜索记得的一句原文，就能找回之前的记录。点击搜索结果就能继续编辑和摘录。需要带走资料时，点击「导出全部便签」即可下载 ZIP。每张便签都有一份 Markdown 文件，压缩包中另附全部便签的 JSON 备份。

小猫便签无需注册。选文、手写内容、最近摘录来源保存在当前浏览器的本机配置中。扩展不会上传便签或跨设备同步。普通 HTTP 和 HTTPS 网页支持划词摘录，具体可用范围取决于浏览器的网站访问设置。

## 审核人员操作说明（单独填写）

1. 无需测试账号。打开允许扩展运行的普通网页，选中一段正文，点击「存入当前便签」。
2. 打开工具栏扩展图标，查看侧栏中的引用。换一个网页再摘录一段，检查两段选文是否出现在同一张便签中。
3. 输入 Markdown 标题或列表，点击「预览」。打开「全部便签」搜索正文，点击结果继续编辑。
4. 点击「导出全部便签」下载 ZIP。解压后可查看每张便签的 Markdown 文件和 `backup.json`。
