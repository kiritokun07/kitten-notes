小猫便签隐私政策

适用版本 0.3.1 · 更新日期 2026 年 11 月 25 日

小猫便签在 Microsoft Edge 或 Chrome 的当前浏览器配置中保存和整理网页摘录。使用本扩展无需注册账号。

在网页上选择文字时

在浏览器允许的 HTTP 和 HTTPS 网页及匹配的内嵌页面中，扩展会在本机临时读取选区文字和位置，用于在选区旁显示保存按钮。普通划词不会写入便签。点击「存入当前便签」或使用选文右键菜单后，扩展才将选文追加到当前便签，并保存此次摘录页面的网址。每张便签保留最近一次摘录的网址，网址可能含查询参数。

编辑和整理便签时

便签标题、正文、最近摘录来源、创建与编辑时间、便签标识，以及当前便签、草稿标识和最近一次正文光标位置，保存在本机浏览器为本扩展分配的存储空间中。这些数据用于编辑、预览、搜索、导出及重新打开时恢复便签。

数据的传输与使用

开发者不会收到便签内容、摘录网址、选区或使用记录。扩展不向服务器上传这些数据，不进行跨设备同步，不使用分析或广告服务，也不出售或向第三方共享用户数据。通过浏览器扩展 API 取得的数据仅用于上述便签功能。Chrome 版本对这些数据的使用遵循 Chrome 网上应用店用户数据政策中的限制使用要求。

Markdown 预览在本机生成，正文中的图片只显示替代文字。若你主动打开正文中的链接，浏览器或邮件应用将按该链接访问目标服务。

导出、保留与删除

点击「导出全部便签」后，浏览器会将全部便签写入下载文件。ZIP 含便签正文和相关记录，可能包括最近摘录的网址。文件由你自行保管或分享。

便签会保留至你在「全部便签」中删除该条记录，或卸载扩展、清除其本地存储。已经下载的 ZIP 独立保存在设备上，需要从下载位置另行删除。
