# 权限及隐私申报说明

## 单一用途

让用户把主动选取的网页文字保存到本地便签，并在浏览器侧栏编辑、检索和导出这些便签。

## 可填入双商店的权限理由

| 权限或访问范围 | 用途 |
| --- | --- |
| `storage` | 使用 `chrome.storage.local` 在当前浏览器配置内保存标题、正文、最近摘录来源、时间和当前便签，以便关闭浏览器后继续使用。 |
| `sidePanel` | 从扩展工具栏图标打开侧栏，在阅读网页时编辑、预览及整理当前便签。 |
| `contextMenus` | 在网页有选区时提供「存入当前便签」菜单项，把用户选择的文字和此次来源网址保存到本机。 |
| 网站访问（内容脚本） | `content_scripts.matches` 包含 `http://*/*` 和 `https://*/*`，并设置 `all_frames: true`。用户可以在不同网站及匹配的网页框架内划词，脚本临时读取选区并在其旁显示按钮。点击保存才将选文和来源写入便签。这个入口需要在划词发生时即可使用。 |

## 远程代码

所有可执行代码都随安装包提供。Markdown 预览使用随包的 markdown-it，ZIP 导出使用随包的 fflate。扩展页面的安全策略将脚本限制在包内，并禁止网络连接。打包时一并包含第三方许可文本。

## 数据使用口径

- **网页内容**包括用户选取的文字，**网址信息**限于最近一次主动摘录时的页面或框架网址。扩展不读取浏览器历史数据库。
- **用户输入**包括标题和 Markdown 正文。另有本机标识、时间及当前便签，用于检索、恢复和导出。
- 选区识别、持久保存、检索和导出均在本机执行。开发者接收量为零。无广告、分析、销售、第三方传输或跨设备同步。用户打开正文链接是由用户发起的外部访问。
- 商店询问“访问、处理或使用哪些数据”时，应披露选文、来源网址及用户输入。询问“是否向设备外传输”时，可填“否”。隐私政策及详细介绍已列明本机处理范围。
- 隐私政策文件为 `privacy-zh-CN.html`。Edge 商店使用[已核验的公开网址](https://kitten-notes-privacy.pages.dev/)。
